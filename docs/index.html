🪦 Repo Autopsy（リポ検死）

公開 GitHub リポジトリの URL を 1 つ入れると、日本語の Mac（Apple Silicon）向け検証レポートを自動で作る CLI。「使える／条件付き／罠」の一次判定を数分で。

GitHub: uminami24-tech/repo-autopsy（MIT License）

使い方（3 コマンド）

git clone https://github.com/uminami24-tech/repo-autopsy.git && cd repo-autopsy
uv sync
uv run autopsy https://github.com/ml-explore/mlx-lm

既定は dry-run（コマンドは実行しません）。--run を付けたときだけ、確認のうえ一時ディレクトリで実行します。

縫い合わせた 5 段（Frankenstein）

  1. fetch — GitHub REST API から README・LICENSE・最終コミット・ファイル一覧を取得
  2. plan — OpenAI 互換 LLM で日本語要約とインストール手順（JSON）を抽出
  3. run — sudo / rm -rf / curl|bash を検出して止め、安全なものだけ使い捨てディレクトリで実行
  4. judge — ルールベース（罠シグナル＋条件付きシグナル）で判定し、根拠を必ず列挙
  5. report — Jinja2 で 8 章立ての日本語 Markdown を生成。MCP サーバー（analyze_repo）としても使える

conda install -c conda-forge mlx-lm

ステップ 3: LLMでテキスト生成を実行します。

mlx_lm.generate --prompt 'How tall is Mt Everest?'

ステップ 4: チャットREPLを起動します。

mlx_lm.chat

ステップ 6: モデルを指定してテキスト生成を実行します。

mlx_lm.generate --model mistralai/Mistral-7B-Instruct-v0.3 --prompt 'hello'

ステップ 7: CLIでモデルを量子化します。

mlx_lm.convert --model mistralai/Mistral-7B-Instruct-v0.3 -q

ステップ 8: 量子化したモデルをHugging Face Hubへアップロードします。

mlx_lm.convert --model mistralai/Mistral-7B-Instruct-v0.3 -q --upload-repo mlx-community/my-4bit-mistral

ステップ 9: 長いプロンプトをキャッシュファイルに保存します。

cat prompt.txt | mlx_lm.cache_prompt --model mistralai/Mistral-7B-Instruct-v0.3 --prompt - --prompt-cache-file mistral_prompt.safetensors

ステップ 10: 保存済みプロンプトキャッシュを使って要約生成します。

mlx_lm.generate --prompt-cache-file mistral_prompt.safetensors --prompt 'Summarize the above text.'

sudo sysctl iogpu.wired_limit_mb=N
