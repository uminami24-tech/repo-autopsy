## インストール手順

以下のインストール手順が確認されました。

```
git clone https://github.com/chatfire-AI/huobao-drama.git
```


**ステップ 2**: プロジェクトディレクトリへ移動します。

```
cd huobao-drama
```


**ステップ 3**: バックエンドの依存関係をインストールします。

```
cd backend && npm install
```


**ステップ 4**: フロントエンドの依存関係をインストールします。

```
cd ../frontend && npm install
```


**ステップ 5**: 開発モードでバックエンドを起動します（ターミナル1）。

```
cd backend && npm run dev
```


**ステップ 6**: 開発モードでフロントエンドを起動します（ターミナル2）。

```
cd frontend && npm run dev
```


**ステップ 7**: 単一サービス用にフロントエンドをビルドします。

```
cd frontend && npm run generate
```


**ステップ 8**: ビルド成果物をバックエンドが読むdistへコピーします。

```
cp -r .output/public dist
```


**ステップ 9**: バックエンドを起動し、APIと静的ファイルを配信します。

```
cd ../backend && npm start
```

```
cd backend && npx tsx scripts/import-mysql-to-sqlite.ts
```
