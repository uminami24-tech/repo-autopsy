# Requirements — 02 Sandbox Run

## 概要

抽出されたインストール手順を安全にチェックし、既定 dry-run でユーザーに内容を提示する。
`--run` フラグと確認プロンプトを経た場合のみ、一時ディレクトリで実行してログを記録する。

---

## 受け入れ基準（EARS 形式）

### FR-20 Dry-run の既定動作

WHEN ユーザーが `--run` フラグを指定せずに `autopsy` を実行したとき、  
THE SYSTEM SHALL いかなるコマンドも実行せず、  
実行予定の手順一覧を日本語で標準出力に表示しなければならない。

### FR-21 危険コマンドの検出と即時停止

WHEN 手順リストにいずれかのパターンが含まれるとき：  
`sudo`、`rm -rf`、`curl ... | bash`、`wget ... | sh`、`chmod +s`、`chown root`、  
THE SYSTEM SHALL そのコマンドを「危険なコマンドを検出しました」と日本語で表示し、  
当該ステップの実行をスキップして「罠」シグナルとして記録しなければならない。

### FR-22 実行前の確認プロンプト

WHEN `--run` フラグが指定されたとき、  
THE SYSTEM SHALL 実行するコマンドの全文を日本語で表示し、  
`y/N` の確認プロンプトを出力しなければならない。  
ユーザーが `y` 以外を入力した場合、実行せずに終了しなければならない。

### FR-23 一時ディレクトリでの実行

WHEN ユーザーが確認プロンプトで `y` を入力したとき、  
THE SYSTEM SHALL `tempfile.mkdtemp()` で作成した一時ディレクトリを作業ディレクトリとして  
各コマンドを実行しなければならない。  
実行完了後または失敗時に、一時ディレクトリを削除しなければならない。

### FR-24 環境変数の最小化

WHEN コマンドを子プロセスとして起動するとき、  
THE SYSTEM SHALL 渡す環境変数を `PATH`, `HOME`, `LANG`, `TMPDIR` のホワイトリストに限定しなければならない。  
`OPENAI_API_KEY`, `ZRO_API_KEY`, `GITHUB_TOKEN` などの秘密情報を子プロセスに渡してはならない。

### FR-25 タイムアウト

WHEN コマンドを実行しているとき、  
THE SYSTEM SHALL 既定 600 秒（10 分）のタイムアウトを設定しなければならない。  
タイムアウトした場合は子プロセスを強制終了し、`RunResult` にタイムアウトを記録しなければならない。

### FR-26 実行ログの記録

WHEN コマンドの実行が完了したとき（成功・失敗・タイムアウトを問わず）、  
THE SYSTEM SHALL 各ステップの stdout・stderr・終了コード・所要時間を  
`RunResult` 型に格納し、後続の judge ステージに渡さなければならない。

### FR-27 実行結果の分類

WHEN すべてのステップの実行が完了したとき、  
THE SYSTEM SHALL 終了コードが 0 のステップを「成功」、0 以外を「失敗」として  
集計し、`RunResult.summary` に記録しなければならない。

### FR-28 非インタラクティブ実行モード

WHEN `--yes` または `-y` フラグが指定されたとき、  
THE SYSTEM SHALL 確認プロンプトを出さずに実行を開始しなければならない（CI 用途）。  
ただし、危険コマンドの検出（FR-21）は `-y` でも回避できない。
