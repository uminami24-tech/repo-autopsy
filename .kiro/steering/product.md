# Product — Repo Autopsy（リポ検死）

## 目的

公開 GitHub リポジトリの URL を 1 つ入力するだけで、日本語の Mac 向け検証レポートを自動生成する CLI ツール。
「使う前に罠を見抜く」という一次判定を、日本語で、数分で提供する。

## 対象読者

**Mac で海外 AI ツールを試す日本の個人クリエイター・開発者**。
- 英語 README の読み解きに時間をかけたくない
- Apple Silicon (arm64) で動くかどうかが最初の関門
- 無料枠で試せるかどうかを事前に知りたい
- 商用利用できるライセンスかを確認したい

## 判定ラベルの定義

| ラベル | 意味 |
|--------|------|
| **使える** | arm64 Mac で主要機能が動作し、無料枠で試せる。ライセンスは商用可。 |
| **条件付き** | 動作するが制限あり（Rosetta 必要、有料 API 必須、非商用ライセンスなど）。条件を明示する。 |
| **罠** | 以下のいずれかを含む：CUDA/NVIDIA 必須、`curl \| bash` / `sudo` 要求、ライセンス無し、1年超放置、実行ログに致命的エラー。 |

## 価値提案

試す前の「使える／罠」判定を日本語で得られる。本ツールの出力は **一次判定** であり、保証ではない。

## MVP の入出力

- 入力: `autopsy https://github.com/owner/repo`
- 出力: `reports/owner__repo.md`（日本語 Markdown、章立て 8 節）
- 実行は既定 dry-run。`--run` フラグと確認プロンプトで初めてコマンドを実行する。
