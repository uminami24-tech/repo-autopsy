# Safety Rules

## 実行の既定動作

- **既定は dry-run**。`--run` フラグを明示したときのみ実行する。
- `--run` 実行前に、実行するコマンド全文を日本語で表示し、`y/N` の確認プロンプトを出す。
- ユーザーが確認しない限りコマンドを実行しない（CI 等で `-y` フラグで自動承認は可）。

## 「罠」に自動分類して実行しないコマンドパターン

以下を含む手順は **実行せず、即座に「罠」判定** に分類する：

- `sudo`（管理者権限の要求）
- `rm -rf`（再帰削除）
- `curl ... | bash` / `wget ... | sh`（パイプ経由の任意コード実行）
- `chmod +s` / `chown root`（SUID/権限昇格）
- 環境変数に API キーを直書きするコマンド（`export KEY=sk-...`）

## 実行時の隔離

- 実行は必ず **一時ディレクトリ**（`tempfile.mkdtemp()`）内で行う。
- 子プロセスに渡す環境変数は **ホワイトリスト最小化**（`PATH`, `HOME`, `LANG` 程度）。
- API キー（`OPENAI_API_KEY` 等）は子プロセスに渡さない。
- タイムアウト: 既定 **600 秒（10 分）**。`--timeout` で変更可。

## 秘密情報の扱い

- API キー・`.env` の値はログ・レポート・標準出力に出力しない。
- `.env` ファイルはリポジトリにコミットしない（`.gitignore` に記載）。
- リポジトリ内には `.env.example`（実値なし）のみ置く。
- コミット前フックで `sk-`、`ZRO_` 等のパターンをスキャンする（hooks で実装）。

## データの制限

- 対象は**公開 GitHub リポジトリのみ**。
- 会社・業務のコード・データ・社内 URL を本ツールに入力しない。
- 非公開リポジトリへのアクセスは実装しない。
